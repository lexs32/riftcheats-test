# Rift Cheats — Test & Staging Repository

Test and preview repository for Rift Cheats web platform.

## Structure
- `index.html` — Homepage with animated hero, interactive video player, reviews, FAQ, and game shortcuts
- `store.html` — Full product store catalog with category filtering and interactive modal drawers
- `status.html` — Real-time game cheat operational status monitor and detection status
- `client-area.html` — Customer dashboard, order history, and license key redemption portal
- `reviews.html` — Verified customer reviews
- `assets/` — CSS, fonts, SVG icons, optimized media assets
- `GLogos/` — Game brand logos and iconography
